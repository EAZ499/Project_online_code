По фактическому коду структуру лучше разделить не на «начало раунда» и «конец раунда» в одном месте, а на отдельные фазы:

- начало боя;
- начало хода врага;
- конец хода врага / начало хода героев;
- выбор персонажа;
- выбор действия;
- исполнение действия;
- конец хода героев / конец полного раунда;
- завершение боя.

Важное исправление: активного `label Underrunefight` в проекте сейчас нет. Он встречается только в комментариях. Реальный вход в бой идёт через `label fightstarts` в `script2.rpy`, затем вызывается `screen fightbegin`.

---

# Карта боевого цикла

```text
script2.rpy
└─ label fightstarts
   └─ call screen fightbegin
      └─ 1_ВРАГ_ДИАЛОГИ.rpy
         ├─ screen fightbegin
         │  └─ Jump("fightbegin12")
         │
         └─ label fightbegin12
            ├─ инициализация боя
            ├─ call first_turn_dialogue
            └─ jump enemy_turn

               └─ label enemy_turn
                  ├─ первый бой:
                  │  └─ call screen enemyattack
                  │
                  └─ следующие раунды:
                     └─ jump enemydialogue
                        └─ call screen enemyattack

                           └─ label afterenemyattack
                              ├─ завершение хода врага
                              ├─ current_round += 1
                              ├─ дебаффы начала раунда
                              └─ выбор персонажа

                                 └─ playerturn
                                    └─ character_to_choose
                                       └─ choose_attacker_screen
                                          └─ playerturn2
                                             └─ buttoms

                                                ├─ fightchosen
                                                │  └─ choose_attack_screen
                                                │
                                                ├─ magicchosen
                                                │  └─ choose_magic_screen
                                                │
                                                ├─ actchosen
                                                │  └─ actchoice1
                                                │
                                                └─ itemchosen
                                                   └─ itemchoice2

                                                      └─ turntarget
                                                         └─ Heroperformsturn
                                                            └─ Heroattacks
                                                               ├─ атака
                                                               ├─ магия
                                                               ├─ ACT
                                                               ├─ предмет

                                                                  └─ choose_attacker_screen
                                                                     └─ если персонажей не осталось:
                                                                        enemyattacklabel
                                                                           └─ enemy_turn
```

# 13. Конец полного раунда

Это место отличается от `afterenemyattack`.

**Файл:**

```text
game/1_ВЫБОР ПЕРСОВ.rpy
```

**Лейбл:**

```renpy
label enemyattacklabel:
```

Он вызывается из `choose_attacker_screen`, когда у всех доступных героев закончились ходы:

```renpy
timer 2.2 action [
    Hide("choose_attacker_screen"),
    Jump("enemyattacklabel")
]
```

Здесь выполняются:

- сброс `current_attacker`;
- сброс сытости персонажей;
- применение эффектов конца раунда:
  - `apply_debuffs_at_round_end()`;
  - `apply_debuffs_at_round_end_enemies()`;
- восстановление HP/MP;
- показ анимации перехода к атаке врага;
- переход в `enemy_turn`.

```renpy
jump enemy_turn
```

Таким образом:

```text
afterenemyattack
= конец хода врага / начало хода героев

enemyattacklabel
= конец ходов героев / конец полного раунда
```

# 14. Завершение боя

## Проверка победы

**Файл:**

```text
game/1_ПОСЛЕ БОЯ.rpy
```

**Экран:**

```renpy
screen check_enemy_status:
```

Он постоянно проверяет:

- убиты ли все враги;
- пощажены ли все враги;
- проиграла ли команда;
- нужно ли перейти к `after_fight`.

## После боя

```renpy
label after_fight:
```

Выполняются:

- подготовка опыта;
- показ `post_battle_xp_screen`;
- проверка `bad_way()`;
- скрытие боевых экранов;
- очистка целей;
- сброс атакующего;
- сброс флагов меню;
- возврат в `game_screen`.
